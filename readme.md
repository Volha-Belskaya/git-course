# Git and Github course

Course for Git
1. Создание заявки: Создание заявки клиента на банковский продукт: Карты

1.1 Сотрудник банка создаёт заявку на выпуск карточного продукта клиенту;
1.2 Заявка сохраняется на ABS Card service и передаётся в топик kafka для валидации;

Статус скоринга - WAITING 
Статус заявки - CREATED
Статус на фронте - Обработка заявки


2. Scoring service

2.1 Scoring service считывает заявку на создание карты и выполняет проверку;
2.2 Scoring service публикует в топик kafka результат валидации заявки;
2.3 ABS Card service считывает результат валидации из топика kafka и меняет статус заявки;

Статус скоринга - APPROVED / DECLINED 
Статус заявки - CREATED
Статус на фронте - Одобрено / Не одобрено


3. Создание счёта: Открытие банковского счета клиента

3.1 ABS Card service отправляет запрос в ABS Account service на создание счёта; (доп. шаг, если счёта нет)
3.2 ABS Account service возвращает ответ в ABS Card service о том, что счёт создан; (доп. шаг, если счёта нет)

Статус скоринга - APPROVED
Статус заявки - CREATED
Статус на фронте - Одобрено


4. Создание договора
4.1 В ABS Card service создаётся договор, в котором отражены условия обслуживания карты и счёта;

(требуется ручное подтверждение)
4.2 Сотрудник банка скачивает сформированный договор, распечатывает и отдаёт на подпись клиенту;

Статус скоринга - APPROVED
Статус заявки - READY_TO_ASSIGN
Статус договора - NOT_SIGNED
Статус на фронте - Готово к подписанию


5.Загрузка договора: Загрузка договора при оформлении банковского продукта: Карты
5.1 Сотрудник банка забирает у клиента подписанный договор, сканирует и загружает в систему;

Статус скоринга - APPROVED
Статус заявки - READY_TO_ASSIGN
Статус договора - SIGNED
Статус на фронте - Подписано


6. Создание карточного продукта: Обработка заявки на выпуск банковского продукта: Карты
6.1 Сотрудник нажимает кнопку для оформления карточного продукта клиенту;
6.2 Создание карточного продукта в ABS Card service;
6.3 При успешном создании продукта ABS Card service возвращает код 201 и меняет статус заявки.

Статус скоринга - APPROVED
Статус заявки - CLOSED
Статус договора - SIGNED
Статус на фронте - Исполнена
